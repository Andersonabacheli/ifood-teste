# 📊 Análise de Pedidos iFood com Python

Este projeto realiza uma análise exploratória de dados de pedidos do iFood utilizando **Pandas** e **Matplotlib**, com foco em **vendas mensais**, **faturamento**, **tempo de entrega** e **comportamento dos clientes**.

## 📁 Estrutura


## 📌 Funcionalidades

O código realiza:

- ✅ Gráfico de vendas por produto (mensal)
- ✅ Gráfico de tempo médio de entrega por mês
- ✅ Gráfico de faturamento mensal por produto
- ✅ Exibe:
  - Produto mais vendido
  - Cliente que mais comprou
  - Forma de pagamento mais usada
  - Tempo médio de entrega
  - Faturamento total

## 📦 Requisitos

Certifique-se de ter o Python instalado (recomenda-se versão 3.8 ou superior) e instale as bibliotecas necessárias:

```bash```
pip install pandas matplotlib

Execute o script:
python main.py
